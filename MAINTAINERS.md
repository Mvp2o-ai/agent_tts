# Maintainers

Current maintainers:

- [@wiltshirek](https://github.com/wiltshirek)
- [@kenainative](https://github.com/kenainative)

Maintainers review pull requests, triage issues and security reports, validate
provider changes, and publish releases. Architecture and security-sensitive
changes should reach consensus between available maintainers; routine changes
may merge after the repository's required review and automated checks pass.

Maintainer access does not bypass `main` protection. Releases are cut from
reviewed commits on `main` using the process in `RELEASING.md`.
