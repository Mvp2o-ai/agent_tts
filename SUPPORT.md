# Support

Start with the setup and troubleshooting guidance in `README.md`, `AGENTS.md`,
and `docs/deployment/`. Search existing issues before opening a new one.

Use the bug-report issue template for reproducible product defects. Include the
affected version, host type, device/OS, harness, selected voice providers, and
sanitized logs. Never include credentials, pairing payloads, private repository
details, or live agent URLs.

Operators remain responsible for their provider account, host, TLS, volumes,
vendor availability, credentials, quotas, and billing. Provider support should
handle account or platform incidents; this project can address defects in its
runtime, mobile app, protocols, and public provider drivers.

Report security issues privately as described in `SECURITY.md`.
